# 单个漏洞证据链

2026-10-16。保留 Codex Security SDK 0.1.25、Go Server + Go Agent + Node Scanner，以及 HTTP、共享产物和 JSONL。用户通过 Web 漏洞详情中的“查看证据链”操作；查询图谱不会启动扫描或调用模型。

## 数据与模块边界

- 新增独立 `FindingEvidence` / `EvidenceGraph` v1 Schema，生成 Go/TS 类型。不改写已有 Job、结果、描述、兼容矩阵或迁移。
- Scanner 是唯一理解 SDK 字段的适配层：提取代码证据 ID、根因/攻击路径/数据流/复核中的 `evidenceRefs` 与 `evidence_refs`，兼容 `dataFlow`、`data_flow`、`dataflow`。通过每个 Finding 的 `extensions.axiomEvidence` 持久化到既有完整结果归档。
- Agent 继续透传完整合同，不解析 SDK 字段，不引入数据库或图谱规则。
- Server 根据已归档事实生成可重建的图谱投影，不引入图数据库。所有节点与关系使用稳定 ID，绑定任务、attempt、漏洞指纹；事实的源码哈希必须匹配冻结来源。
- Web 复用 ECharts graph，按需加载 SVG 渲染器，按容器实际宽度重排一至四列。图谱、列表和证据检查器读取同一组事实。

原始 SDK 对象保持完整。`sourcePointer` 使用 RFC 6901，相对于返回的 `sourceFinding` 定位到具体字段；`archiveSha256` 标识本次完成信封，不冒充某个导出文件的摘要。源码文件匹配另记录自己的 SHA-256。

可定位还不足以证明映射正确：代码片段、位置和 SDK 证据 ID 必须与 Pointer 指向的原始条目一致；支持边的起点证据 ID 必须与该原始引用一致。Go/TS 与 Web 读取防护均检查这些约束。

## 状态语义

| 状态 | 产生条件 | 不代表什么 |
|---|---|---|
| 推断 | SDK 输出的漏洞、路径、支持/反证关系和复核结论 | 不代表实际执行或漏洞已复现 |
| 已观察到代码 | Server 确认保留的源码树哈希与冻结哈希一致，并逐行匹配指定代码片段 | 不证明这段代码可达、数据流成立或漏洞存在 |
| 已验证 | 合同要求独立的运行或人工验证记录、产物哈希与依据；当前投影器不会自行产生该状态 | SDK 的 `verified` / `reportable` 字符串不能触发升级 |
| 未知/存在反证 | 合同为证据状态保留明确表达 | SDK 反证文字本身仍按推断展示 |

代码比较规范化 CRLF 为 LF，并忽略片段的单个结尾换行；不忽略缩进或内部空白。全树完整性校验有 2 秒上下文预算，单个检查文件上限 4 MiB。缺失、内容变化、符号链接、特殊文件、过大文件或位置不匹配都保留原始 SDK 片段和原因，不升级观察状态。

`describes_next` 只表示 SDK 列出的步骤/数据流次序，不是静态调用图或真实污点传播。代码证据数组的位置、相邻文件、文本中的箭头都不能产生支持关系；只有明确且唯一的证据 ID 引用才能连支持边。缺失和重复引用保留诊断，不补造关系。

`complete` 仅表示已有字段的图谱映射完整，不表示审计完整、验证完成或路径不存在缺口。

## 查询与历史兼容

`GET /api/v1/scans/{id}/attempts/{attempt}/evidence-graph?fingerprint=...`

需要已登录的 read 权限；viewer 可以调查。该接口没有写入方法。明确指定 attempt，不从当前索引、全局去重列表或其他扫描混入证据。

- 200：当前归档的图谱及来源对象。
- 400：缺失或无效的执行/漏洞选择。
- 404：执行无归档、指纹不属于该批次，或旧 Server 未提供该入口。
- 409：证据合同、身份、哈希绑定或原始引用不一致。
- 503：归档读取暂时不可用。

图谱无效不使原始报告失效。历史完成信封和没有新扩展的结果使用 `legacy_projection`，只读取已有的可移植字段；Go 不解析 SDK 文本或猜测原生别名，不回写历史对象。旧数据没有足够结构时显示证据不足，并保留描述、结果和原始 JSON。

图谱最多 256 个节点、1024 条关系。Scanner 超量时明确记录映射缺口并保留原始对象；Web 默认展开最多 48 个节点，可继续展开，始终显示当前/总数量。图谱扩展导致完整结果接近容量上限时，先撤去可重建投影并写入原因，保留原始证据。

## Web 交互

入口位于现有 Finding Inspector，保持漏洞列表、选中对象和执行批次。支持证据关系/攻击路径、图谱/列表、节点和连线选择、缩放、适应画布、证据关联跳转、源码位置与哈希、对应原始字段及完整来源对象。图谱方向键选择，Enter 聚焦详情，Esc 清除选择；列表和定位选择器提供可访问的同等入口。

读取失败提供重试。版本、执行、源码或引用不匹配时拒绝显示图谱；不会自动重新执行扫描。内部图谱投影不再混入“SDK 扩展字段”的普通文本列表，原始数据仍能完整读取。

布局根据节点字号、标签内边距和现有间距 Token 选择列数；减少列数时纵向增加画布，SVG 尺寸同步更新，单列和单节点保持像素坐标。标签中的换行只在画布上折叠，完整名称和原始对象保留在检查器中。按钮及滚轮缩放同时缩放节点和文字；选择对象保留当前缩放和平移，容器尺寸变化时重新适应画布并保留选中证据。布局不增加、删除或改写任何节点、关系与证据状态。
