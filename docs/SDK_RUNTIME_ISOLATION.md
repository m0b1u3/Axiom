# SDK 官方运行路径与兼容环境隔离

2026-10-28 开始收敛，2026-10-29 补齐 DeepSeek 原生 V2 消息兼容，并追加 Deep、真实中断续扫、组件与 Git 差异的本地真实验收；SDK 保持 0.5.0，Codex 保持 0.163.0，协议保持 Responses + 原生 Schema。当前证据限于所测小型合成项目，不代表 VPS 已部署或所有模型、项目规模均已通过。

## 依赖与插件

`node_modules/@openai/codex-security` 恢复官方发布文件。原先修改过的默认配置、四份子任务说明、MCP 环境变量列表及自定义验证的说明文件指纹均恢复到 manifest 中的 upstream SHA-256。

安装器从同一版本生成独立的 `@axiom/codex-security-compat-v1` 运行包，现有七处兼容修改只存在于该包。两份包共享锁定版本的 Codex 与依赖，不复制平台业务逻辑。兼容包保留历史固定字节；其中未在 Web 开放的 fix-finding 说明不作为新功能启用。

`deploy/sdk/upstream/` 保存七个经原始哈希验证的上游文件，`overrides/` 保存兼容字节。安装前检查完整文件清单及依赖，未知修改拒绝继续。`npm run verify:sdk` 同时验证官方包、兼容包和运行描述。执行时再次核对版本及关键文件指纹。运行中的任务不会通过改写公共 SDK 文件来切换环境。

## 连接选择

| 连接 | 新任务的运行环境 |
| --- | --- |
| ChatGPT 授权、官方 OpenAI 连接 | 官方 V2；不使用 V1 配置和修改后的插件说明 |
| DeepSeek 预设且端点为 `https://api.deepseek.com` | 官方 V2；在 Responses 传输层限定转换其无法消费的内部任务消息 |
| 部署配置明确登记的兼容连接 | legacy V1 |
| 其他兼容接口 | 官方 V2；能力仍须按真实验收结果判断 |

模型名称不参与运行环境选择。第三方接口上的 GPT 名称不等于官方 OpenAI 连接；连接成功也不等于子任务、Schema 或报告能力已验收。

需要保留旧连接的 V1 行为时，在 Agent 环境变量 `AXIOM_SDK_LEGACY_CONNECTIONS` 登记精确的 provider/baseUrl，可进一步限定 model。DeepSeek 不再因端点自动降为 V1；旧绑定和显式登记仍有效。该配置只选择 SDK 兼容环境，不是网络访问授权。例如以下是合成配置，不应直接用于生产：

```json
[{"provider":"custom","baseUrl":"https://fixture.invalid/v1","model":"fixture-model"}]
```

升级现有部署前须核对其真实连接地址并填写对应配置；不能因为模型名包含 DeepSeek 而自动推断网关需要 V1。官方 OpenAI 路径不受此列表降级。没有自动协议回退或第二层模型请求重放；请求和流重试继续归 SDK 所有。

## 每次执行的记录

`logs/sdk-runtime.json` 保存运行环境 ID、SDK/Codex/插件版本、关键文件指纹、配置摘要及执行身份；不保存 API Key、授权内容或凭据目录。该记录作为带 SHA-256 的产物随新结果归档。标准结果 `extensions.sdkRuntime` 保存环境 ID 和指纹，官方结果的 `patchRevision` 为空，兼容结果记录其补丁基线。

环境在任务开始时冻结。同一执行目录不能被另一个环境或配置覆盖；并行任务分别使用自己的输出目录、状态与插件安装投影。扫描、组件建议、组件执行、预检及独立复核均使用相同选择规则。

## 历史与恢复

历史报告、源码快照、既有单价和费用不回写、不重新估算。旧结果仍由 SDK `loadContract()` 读取和验证。

新导出的父扫描状态携带运行环境 ID/指纹。跨环境、跨 SDK 版本的私有状态不得导入；无环境标记的历史父状态视为旧 V1 状态。新 V2 扫描不能静默接用这些状态，可以新建独立扫描。

已有 Deep 执行续扫继续绑定原来的环境；无环境记录的旧执行使用封存的 legacy V1 基线。新 Deep 恢复清单包含环境绑定，核验时同时校对执行记录，既有源码/身份/节点/检查点/排他锁校验继续生效。

## 验收范围

隔离测试验证两个运行包的文件与配置、连接精确选择、官方 OpenAI 不被兼容配置降级、原生封存结果读取、父状态拒绝跨环境复用，以及进度、用量和各任务入口回归。官方 SDK Mock 不构成真实子任务可用性的证明。

本地真实验收使用已登录的 ChatGPT 身份与 gpt-6.1-terra，检查 V2 子任务收到并执行指令，以及小项目扫描、复核报告、归档与证据图谱。实际结果和限制记录在对应验收 JSON，不能以此宣称所有供应商和扫描方式均已验收。
