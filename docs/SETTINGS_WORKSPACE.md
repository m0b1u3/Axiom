# 设置工作区

系统设置按使用目的分组，复用现有模型、授权、调度、存储与账户组件。后台仍为 Go Server + Go Agent + Node Scanner，SDK 固定 0.1.25；API、共享产物与 JSONL 合同不变。

| 区域 | 入口 | 内容 |
|---|---|---|
| 日常设置 | 模型与授权 | 模型配置、供应商 API Key、独立 API Key / ChatGPT 授权账户 |
| 日常设置 | 扫描执行 | 当前执行、排队与在线节点；平台并发配额已停用 |
| 日常设置 | 存储与清理 | 容量、领取阈值、保留策略及可恢复清理流程 |
| 日常设置 | 账户与外观 | 密码、登录会话及主题；作为设置页默认入口 |
| 管理员 | 账户管理、操作日志 | 工作空间用户与角色、操作者和对象的历史记录 |
| 高级 | 高级诊断 | 执行节点、兼容合同、授权绑定及凭据版本、配置变更、原始快照与运行架构 |

模型配置和授权账户共用“模型与授权”工作区的两个页签。模型仍可直接保存供应商 API Key；原生 OpenAI 模型也可在扫描时选择独立授权。模型的增删改、搜索、状态筛选、连接测试、模型列表与工作模型开关继续调用原 API。授权账户的 API Key 登录、设备码指引、取消、账户查询、撤销及退出清理保持原执行链路，不因浏览设置自动启动。

日常授权表单从实际上报的执行位置选择绑定节点。只有一个位置时可预选；没有位置时不会伪造可用节点。尚未上报的 Agent ID 可在高级诊断中手动指定，再返回添加授权账户，原有绑定能力仍可通过 Web 完成。凭据版本、节点原始上报和授权操作版本记录保留在高级诊断。切换授权页签会清除未提交的 API Key；扫描执行保留上次读取的快照，切回时重新读取。

## 旧链接

- `/settings/model-configs` 跳转到 `/settings?section=models&tab=models`。
- `/settings?section=sdk-identities` 跳转到 `/settings?section=models&tab=accounts`。
- 旧模型与授权链接的其他查询参数及 hash 保留。
- `section=execution/storage/account/users/operations/about` 继续可用，新增 `section=diagnostics`。
- 任务中的授权链接携带身份 ID；诊断可返回同一账户，保留调查上下文。

管理员区域仅对已确认具有管理员权限的账户显示。非管理员访问其旧链接会收到明确的权限提示，相关组件和写操作不会加载；Server 的权限校验继续生效。旧身份响应缺失权限字段时沿用只读处理，不提升权限。

存储默认保留历史任务、报告和费用证据，清理预览与确认流程不变。原始容量快照转至高级诊断，存储管理提供直接入口。历史扫描、结果、报告和证据图谱的路由及读取接口不变。

## 诊断数据阅读

节点、调度、授权和存储快照统一使用 `DiagnosticSnapshot`。原始数据默认收起，摘要显示 JSON 行数及 UTF-8 大小；展开后可切换自动换行、复制完整 JSON 或下载 JSON。数据不截断，键盘可展开和滚动阅读；复制、下载失败有明确提示。快照在独立区域内滚动，避免长 JSON 把整页撑开。刷新失败仍保留并标识上次成功读取的证据。

桌面设置分类保持在视口内；1100px 以下恢复随文档排列，窄屏表格保留本地横向滚动。沿用现有中性色、字体和浅色/深色主题，不改变 API、权限或 SDK 行为。

## 回归入口

`code-audit-web/tests/settings-web-acceptance.mjs` 使用明确标记的临时 Server 和浏览器 API 投影，拒绝将写操作发往现有业务端口。供应商探测使用明确的 Fixture 响应；脚本不执行真实 SDK 登录、扫描或外部发布。

`cd code-audit-web && npm run test:diagnostics` 单独运行诊断样式回归。脚本自行启动内存中的只读 Fixtures / Mock API 和临时 Web 端口，检查四类原始数据的一致性、复制与下载、键盘操作、读取失败恢复、管理员边界，以及 320/390/900/1440 宽度与浅色/深色截图。无需 PostgreSQL、真实账户或 SDK 调用；默认结果写入 `output/playwright/diagnostics-style`，CI 同步运行并保存证据。

`TestSDKIdentitiesPipeline` 在 `AXIOM_TEST_WEB_IDENTITIES=1` 时顺序执行原 SDK 身份浏览器验收和设置工作区验收，覆盖原生 SDK 模拟登录、取消、撤销及凭据版本追溯。现有前端完整性、权限、兼容性与存储浏览器脚本已同步新的分组和入口。CI 保留浏览器结果与截图，排除私有捕获文件。
