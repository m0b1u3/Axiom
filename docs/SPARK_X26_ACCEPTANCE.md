## Schema 的明确反例

两次用户输入完全相同：`计算17乘以23，只给出结果。`

- 第一条要求输出对象，必须具有整数属性 `result`。
- 第二条只改变 Schema：要求输出对象，`result` 必须为字符串枚举 `PUBLIC_SCHEMA_CHECK`。
- 两条都收到 HTTP 200 / completed，却均返回裸文本 `391`，而非任何一种要求的对象。接口报告的输入 Token 也均为 31。

因此，第一条提示驱动的 JSON 成功不能证明强制 Schema 可用。当前 SDK 所发送的标准 Responses Schema 参数在这些测试中没有得到执行；不以改成 JSON 模式、Chat、放宽本地校验或猜测替代参数来宣称通过。此结论限于提供的接口和本次参数，不等于否定所有 Spark 服务或其他供应商接法。

原生 V2 探针还观察到该模型没有提供消息 `phase` 元数据；核对时查看了实际响应与完成状态，没有仅因缺少 `phase` 就认定没有回复。重复派发的探针按 180 秒时限结束，未作为完整扫描结果归档。
