# 0.1.0-beta.2 源码候选

创建日期：2026-10-27；更新：2026-10-30。支持 Linux amd64、单主机、可信用户自托管。发布状态为源码候选；公开 Release 须另行核对同一完整 Git SHA 的五项 CI、源码交付和安全报告入口。

## 本批变化

- SDK 0.5.0 / Codex 0.163.0，当前源码 Scanner description 15、结果适配器 2；参考 VPS 仍为 description 14。官方包恢复原生 V2，旧 V1 补丁仅在显式兼容包中；保留历史 reader 和旧 SDK 私有父状态隔离。
- Responses 输入与 namespace 工具兼容、发送前字段校验、严格报告正文和冻结源码引用检查。移除 Chat 适配；原生 Schema 不自动降级，失败请求不自动重放。
- 独立复核及组件计划不再请求不适用的扫描对比。新执行移除 SDK 内置模型单价与金额回调，扫描、复核、组件及跨组件匹配按实际 Token 与平台冻结单价估算；旧原始费用归档保持。
- 静态 Web 升级保留旧动态模块，页面加载失败提供单条中文提示和手动恢复，不自动刷新未提交表单或重放任务。
- 修复后台费用刷新使「重新执行」确认读取失效的竞态；确认对话、执行身份和服务端预算复核保持，浏览器回归明确覆盖响应交错。
- 通用模型价格、缓存计价、实际 Token 估算、不可变执行价格快照及迁移 028；缺价或用量保留未知，历史费用不追溯重算。
- 新建扫描预算接入冻结的 USD 单价与实际 Token，缺必要用量或额度耗尽后阻止后续请求，保留部分结果。DeepSeek 的消息格式与嵌套 Schema 兼容仅限经过真实对照的连接，不改 SDK 原文和源码校验，不回退 V1、Chat 或 JSON 模式。
- 当前状态、验收摘要、安装与回滚文档统一；历史部署证据由哈希绑定的 limited 表示，最新本地真实补测另有脱敏记录。小项目实测、完整候选认证和供应商账单核对分别保留范围。

## 验收与限制

已有 DeepSeek 小项目完成扫描、原生 strict Schema 复核、源码检查、正式归档和交互图谱，共 59 次历史请求，失败及自动重试均为 0。此证据属于计价功能上线前的记录，不表示本候选、全部 SDK 能力或全部供应商已真实验收。

2026-10-29 本地原生 V2 补齐 Deep、真实中断续扫、组件及匹配、Git 差异，5 次独立复核、19 处摘录与 40 项关键下载通过。2026-10-30 隔离验收覆盖 348 项 Scanner、511 项合同、102 项 Web，以及匹配、组件、配置计价和预算专项链路。后续真实补测中，两个组件发现原生归并成 1 组，146 次扫描及匹配请求的完整用量按冻结单价估算 `$0.399327`，两份严格 Schema 复核、9 处摘录、17 项下载和完整图谱通过；V2 运行中消息也实际送达。详见[真实补测记录](../acceptance/component-matching-real-20261030.json)。

原 32 次执行、652 个归档与历史单价、费用不变。V2 消息探针中原生抢占取消一个响应，该探针完整费用仍未知；未返回的缓存写入量保持 null。组件的 shell 临时写入拒绝在同次执行内恢复，没有扩大写权限。供应商账单、更多真实项目及长期稳定性尚未完成，GLM 等待提供方修复后单独复测。验收配置采用既有人工单价快照；不自动抓取官网价或换汇。源码交付检查不能代替远端 CI。

参考部署继续为 DeepSeek / deepseek-flash + Responses + native_schema，本候选整理不重新部署 VPS。旧镜像保持其原标签，精确 ID 和范围见 [脱敏部署摘要](../acceptance/pricing-deployment-20261027.json)。

## 升级提示

先完成一致性备份，按 Server → Agent / Scanner → Web 切换配套版本，保留数据库、产物、身份与密钥。新计价记录出现后，退回不认识新费用来源的版本需要先在独立副本验证，不能直接覆盖现有历史。操作见 [安装与回滚](../BETA_INSTALLATION.md)、[模型计价](../MODEL_PRICING.md)。
