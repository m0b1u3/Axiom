## 本批变化

- SDK 0.5.0 / Codex 0.163.0，Scanner description 14、结果适配器 2；保留历史 reader 和旧 SDK 私有父状态隔离。

## 验收与限制

已有 DeepSeek 小项目完成扫描、原生 strict Schema 复核、源码检查、正式归档和交互图谱，共 59 次历史请求，失败及自动重试均为 0。此证据属于计价功能上线前的记录，不表示本候选、全部 SDK 能力或全部供应商已真实验收。

计价实现的 498 项合同、290 项 Scanner、94 项 Web、Server Store / HTTP、Agent、离线完整流程和桌面 / 窄屏验证已通过。既有部署完成断网备份恢复及两次迁移打开，历史数据和费用保留。本次文档与发布检查只执行本地无模型验证；源码交付检查不能代替远端 CI。

新计价真实用量核对、供应商账单、更多真实项目及长期稳定性尚未完成。GLM 等待提供方修复后的单独复测。实际价格未填写；不抓取官网价或自动换汇。

参考部署继续为 DeepSeek / deepseek-flash + Responses + native_schema，本候选整理不重新部署 VPS。旧镜像保持其原标签，精确 ID 和范围见 [脱敏部署摘要](../acceptance/pricing-deployment-20261027.json)。

## 升级提示

先完成一致性备份，按 Server → Agent / Scanner → Web 切换配套版本，保留数据库、产物、身份与密钥。新计价记录出现后，退回不认识新费用来源的版本需要先在独立副本验证，不能直接覆盖现有历史。操作见 [安装与回滚](../BETA_INSTALLATION.md)、[模型计价](../MODEL_PRICING.md)。
