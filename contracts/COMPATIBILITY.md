最新 Server 支持控制接口 1–4，并发布矩阵摘要。带摘要的 Server 与 Agent 必须使用同一份矩阵；摘要不一致会阻止模型启动，并上报配套组件诊断，不能据包版本猜测兼容。旧组件缺少运行元数据时，以已声明合同能力判定，缺失的版本显示为未知。新 Agent 只用 presence 探测旧 Server：仅 404/405 可尝试下一接口；认证、网络和数据错误不降级。领取失败不切换接口，已领取任务的固定合同不降级。不支持的格式在模型启动前拒绝。

升级顺序：Server 消费者及迁移 → 配套 Agent/Scanner → Web。旧 Agent/Scanner 只能领取其支持的任务，新 Web 任务保持输入/结果/观察 1/1/1。历史任务、结果、日志、覆盖报告和 HTML/PDF 报告读取器保留。未知合同不能推断为兼容。运行诊断每 10 秒上报，30 秒后失效；在线槽位与通过预检的可用槽位分别展示。缺少、无效或未知版本的 Scanner 描述会阻止新 Agent 领取任务，并向新版 Server 上报诊断。
